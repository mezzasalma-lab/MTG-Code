# Regras do Formato Commander (EDH)

## Regras Básicas

- **100 cartas** exatas no deck, incluindo o comandante
- **Singleton**: apenas 1 cópia de cada carta por nome (exceto terrenos básicos)
- **Identidade de cor**: determinada pelos símbolos de mana no custo de mana E nas caixas de regras do comandante (incluindo mana de ativação, custos alternativos, indicadores de cor)
- O comandante começa na **zona de comando** e pode ser conjurado a partir dela
- **Imposto de comandante**: +2 de custo genérico para cada vez que o comandante foi conjurado da zona de comando anteriormente
- Dano de comandante: 21 pontos de dano de combate do mesmo comandante eliminam o jogador

## Parceiros (Partners)

- Comandantes com "Partner" permitem usar **dois comandantes**
- A identidade de cor é a união das identidades dos dois
- "Partner with [nome]" é exclusivo — só funciona com a carta específica nomeada
- "Friends forever" funciona como Partner mas apenas entre cartas com a mesma habilidade

## Zona de Comando

- Quando o comandante vai para o cemitério ou é exilado, o seu controlador pode movê-lo para a zona de comando
- Isso é uma substituição de efeito, não uma resposta à pilha

## Vida inicial

- Cada jogador começa com **40 pontos de vida**
- Dano de comandante acumulado de um mesmo comandante: **21 pontos** = eliminação

## Análise de Deck — Checklist Detalhado {#analise}

### Passo 1: Validação formal
- [ ] Exatamente 100 cartas (com comandante)
- [ ] Todas as cartas respeitam identidade de cor
- [ ] Nenhuma carta banida
- [ ] Singleton respeitado (listar duplicatas se houver)

### Passo 2: Mana base
- [ ] Contagem de terrenos (ideal: 36-38 para curva normal, 33-35 para decks acelerados)
- [ ] Fontes de cor adequadas para as cores do deck
- [ ] Terrenos utilitários (Command Tower, Exotic Orchard obrigatórios em decks multicoloridos)
- [ ] Fetch lands / shock lands (para Bracket 3-4)
- [ ] Terrenos que entram sem condição vs. terrenos condicionais (Taplands penalizam muito em Bracket 3+)

### Passo 3: Curva de mana
- [ ] CMC médio do deck (ideal para Bracket 3-4: 2.5-3.5)
- [ ] Cartas jogáveis nos turnos 1, 2 e 3
- [ ] Picos de mana — muitas cartas de 5+ CMC sem aceleração é problema

### Passo 4: Ramp (Aceleração de Mana)
Mínimo recomendado por Bracket:
- Bracket 2: 8-10 peças de ramp, CMC médio do ramp até 3
- Bracket 3: 10-12 peças, incluindo rocks de 2 manas (Arcane Signet, Mind Stone)
- Bracket 4: 12+ peças, fast mana incluída (Mana Crypt, Chrome Mox, etc.)

Tipos de ramp:
- **Mana rocks**: Sol Ring, Arcane Signet, Fellwar Stone, Thought Vessel
- **Mana dorks**: Llanowar Elves, Birds of Paradise (verde)
- **Ramp de terra**: Cultivate, Kodama's Reach, Farseek, Skyshroud Claim
- **Fast mana** (Bracket 4): Mana Crypt, Mana Vault, Chrome Mox, Mox Diamond

### Passo 5: Card Draw
Mínimo: 10 fontes de draw/card advantage.
- **Draw neutral**: Rhystic Study, Mystic Remora, Phyrexian Arena
- **Draw condicional**: Vanquisher's Banner (tribal), Fathom Mage (counters), etc.
- **Looting/Filtering**: Faithless Looting, Preordain, Brainstorm
- **Burst draw**: Wheel of Fortune, Windfall, Lifeblood Hydra

### Passo 6: Remoção
Distribuição ideal (Bracket 3-4):
- 4-6 remoções pontuais de criatura
- 2-3 remoções de artefato/encantamento
- 1-2 remoções de planeswalker
- 2-3 board wipes
- Preferir exile sobre destruction em Bracket 3+ (ressurreição é comum)

Remoções de referência:
- Exílio criatura: Swords to Plowshares, Path to Exile, Generous Gift
- Exílio permanente: Chaos Warp, Beast Within, Vindicate
- Wipe: Wrath of God, Damnation, Cyclonic Rift (overloaded), Farewell
- Spot removal versátil: Generous Gift, Beast Within, Chaos Warp

### Passo 7: Win Conditions
- Mínimo 2-3 win conditions distintas (para resiliência)
- Para Bracket 3: combos de 3 peças são aceitáveis
- Para Bracket 4: combos de 2 peças são esperados
- Sempre avaliar: quantos tutores o deck tem para encontrar as peças?

### Passo 8: Sinergia
- As cartas temáticas suportam o plano geral?
- Existem "nonbos" (cartas que se contradizem)?
- O comandante é central ao plano ou funciona como apoio?

## Glossário de Termos

| Termo | Significado |
|-------|-------------|
| Tutor | Carta que busca outra carta específica no deck |
| Rock | Artefato que produz mana |
| Dork | Criatura que produz mana |
| Wipe | Destruição em massa de permanentes |
| Stax | Estratégia de lock/desaceleração dos oponentes |
| Voltron | Estratégia de matar com dano de comandante (21 points) |
| Goodstuff | Deck sem tema específico, só boas cartas |
| Stompy | Deck de criaturas grandes e agressivo |
| Wheel | Cartas que fazem todos descartarem e comprarem novas mãos |
| Fast mana | Mana acceleration muito eficiente (Bracket 4) |
| Cantrip | Mágica que substitui a si mesma comprar uma carta |
| Nonbo | Duas cartas que se contradizem/atrapalham |
| Toolbox | Deck com muitos tutores e soluções situacionais |
