# Avengers Assemble (Marvel Super Heroes Commander) — Captain America, Team Leader / Director Nick Fury

**Registro 2026-09-21**: lista 100% oficial e completa (nenhuma carta faltando,
nenhuma inventada). Fonte primária: página oficial de decklists da Wizards
of the Coast, `magic.wizards.com/en/news/announcements/marvel-super-heroes-commander-decklists`
(publicada 2026-06-08, produto lançado 2026-06-26, set code `msc` no
Scryfall). Todas as 100 cartas (1 comandante + 99 no deck/terrenos) foram
confirmadas uma a uma via Scryfall (`/cards/collection` em lote, 0
"not_found") e a identidade de cor de cada carta foi checada contra W/U/R
(Jeskai) — 0 cartas fora dessas 3 cores, confirmando que não houve erro de
parsing/split de nome.

**Checagem de flavor_name (Regra #2 do CLAUDE.md)**: o set `msc` tem 15
cartas com `flavor_name` (nome de capa) diferente do nome real — as que
pertencem a este deck são: Raise the Palisade↔"Raise Repulsor Shields",
Fellwar Stone↔"S.H.I.E.L.D. Spy Satellite", Herald's Horn↔"Avengers
Monitoring Station". Confirmado programaticamente: o texto oficial da
Wizards usa o `name` real (oracle) em 100% dos casos, nunca o nome de
capa — registrado aqui com o nome real igual à fonte oficial.

**Ambiguidades de parsing resolvidas via Scryfall** (a página não separa
cartas por vírgula/linha de forma 100% inequívoca — cada uma confirmada
como carta real e distinta via `/cards/named?fuzzy=`): "Captain Mar-Vell,
Space-Born" (Kree Soldier Hero, set `msh`) e "Patriot, Shield Wielder"
(Human Hero, set `msh`) são 2 cartas separadas, não uma só quebrada
errado. Idem "Speed, Young Avenger" (Mutant Hero, `msh`) e "Captain
America, Living Legend" (Human Soldier Hero, `msh`) e "Avengers Tower"
(Land, `msh`) — todas reprints do set principal `msh` (Marvel Super
Heroes) incluídas dentro do deck de Commander, por isso não aparecem no
set `msc` isoladamente, só via busca direta por nome.

**Nota sobre "Director Nick Fury"** (correção 2026-09-21, apontada pelo
usuário): a Wizards descreve esse card como comandante alternativo
("Director Nick Fury will keep your hand stocked with Heroes...").
Numa 1ª passada eu tinha registrado só Captain America no `##
Comandante` (raciocínio: "o produto físico só inclui 1 carta foil de
comandante"), mas o usuário corrigiu — mesmo padrão do Warhammer 40k/
Marvel Fantastic Four: **2 comandantes possíveis, escolha de qual vira
comandante único** (não Partner), não uma questão de qual carta vem
foil. Director Nick Fury tem a mesma identidade de cor Jeskai (W/U/R)
do deck, confirmado no Scryfall. Movido de `## Deck` pra `##
Comandante` aqui.

**Nota sobre nomes com sufixo de deck**: a página da Wizards linka Arcane
Signet/Sol Ring/Command Tower com sufixo do deck ("Arcane Signet
Avengers", "Sol Ring Avengers", "Command Tower Avengers") só para
diferenciar a arte/impressão entre os 4 decks no mesmo artigo — são as
MESMAS cartas de sempre (Scryfall confirma: sem esse sufixo, `name` real
é só "Arcane Signet"/"Sol Ring"/"Command Tower"). Normalizado para o nome
real aqui.
